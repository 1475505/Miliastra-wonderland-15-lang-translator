千星奇域十五国语言直接翻译工具。

> ⚠ 本工具仅供学习交流使用，**禁止售卖**。
> 用户QQ群：**1007538100**

输入：「多语言文本管理」导出的 CSV（15 种语言）。

# 如何使用

1. 打开 `release` 文件夹下的 exe。
2. 选择输入 CSV 和输出目录。
3. 填写 LLM 选项（Endpoint / Model / API Key，API Key 必填）。
4. 按需勾选翻译选项：
   - **覆盖已有**：即使目标语言列已有内容，也用 LLM 翻译重新填充。
   - **强制全部翻译**：所有行都参与翻译。
   - **后处理验证**：校验并修正格式标签，检查同一中文是否对应同一译文。
5. （可选）在「自定义额外提示词」中追加额外要求，会附加到 system prompt 末尾。
6. 点击「开始翻译」，等待输出 CSV 和报告。

运行中可随时暂停，再次点击「继续翻译」会从断点续跑。

# 工作原理

- 按 `简体中文` 去重，同一个中文只请求一次，确保所有重复行使用同一套译文。
- 每一个唯一中文一次性翻译全部 15 种目标语言。
- 未改动的源文、代码、格式标签与占位符会按规则原样保留。
- 可以在「自定义额外提示词」中追加要求，例如：保持整体风格轻松口语化、
  统一女性代词/男性代词、禁止扩写、严格按源文长度翻译等。

# 输出

- 翻译结果：`*_direct.csv`
- 报告：`*_direct_report.csv`
- 运行日志：`*_direct_report_<时间戳>.jsonl`

如果勾选了「后处理验证」，还会输出修正后的 `*_validated.csv` 与
`*_validation_report.csv`。

# 强制规则

1. `是否需要翻译` 为 `FALSE` 的行不处理。
2. 同一个 `简体中文` 在所有重复行中必须使用同一套译文。
3. `<...>`、`{...}`、`\n`、数字变量、格式标签必须原样保留，顺序也要保留。
4. 源文不是中文，或只是代码、标签、占位符、数字、纯符号时，原样填入缺失语言列。
5. 只填写空白目标语言单元格。已有译文默认不覆盖。

# 打包

在项目根目录运行：

```bat
pyinstaller QXQY_Direct_Translator.spec --clean --noconfirm
```

生成的 exe 位于 `dist/` 目录，窗口与 exe 均使用 `app/icon.ico` 作为图标。
界面采用 Google Material Design 3 (M3) 配色与布局。
