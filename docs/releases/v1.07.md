## 下载与使用

Windows 64 位用户可以直接下载 EXE；ZIP 额外附带 README 和自编的术语表示例。无需安装 Python。

首次打开先填写 API Key，再选择「多语言文本管理」导出的 UTF-8 CSV。术语表可选，不导入也能翻译。

发布包不包含原神内置术语表、个人术语或 settings.json。自编示例仅用于展示导入格式。API Key 和个人设置只保存在运行程序所在目录。

SHA256SUMS.txt 提供本次两个下载包的 SHA-256 校验值。
